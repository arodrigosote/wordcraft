# ICASYS Documentos

**ICASYS Documentos** es la edición de [ICASYS](https://icasys.mx) de **WordCraft**, hecha por el equipo de ArtCraft ([getartcraft.com](https://getartcraft.com)). Es una versión modificada con identidad propia para uso educativo.

Lee [ICASYS.md](ICASYS.md) para la atribución, las licencias y cómo se construye y actualiza esta edición. El README original del proyecto se conserva en [README.upstream.md](README.upstream.md).
